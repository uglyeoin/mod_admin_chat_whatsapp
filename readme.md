# Chat via WhatsApp

A Joomla administrator module that adds a "Support via WhatsApp" link to the
admin, so editors can message you in one click.

- Pick the country code and enter the number. Spaces, a leading zero, or a
  repeated country code are all cleaned up.
- WhatsApp Business accounts can pre-fill the opening message; the site name
  is added after it so you know which site the message is about.
- Publish it in the `menu` position and it styles itself as an admin menu item.

## Requirements

- Joomla 5.0 or later (tested on Joomla 6)
- PHP 8.1 or later

Updates come through the Joomla updater from kindofuseful.com.
